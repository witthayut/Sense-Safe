คู่มือการต่อสาย — สายรัดข้อมือ Sense&Safe

บอร์ด ESP32-C3 Super Mini  ·  AH024 + GY-MAX30102 + MPU-6050

โครงการ Sense&Safe — LD Haptic Drive Assistant  ·  คณะ ICT มหาวิทยาลัยมหิดล  ·  8 ก.ย. 2569

ถอดสาย USB ออกก่อนต่อสายทุกครั้ง — ต่อให้เสร็จหมดแล้วค่อยเสียบไฟ การต่อสายขณะมีไฟ ถ้าพลาดไปแตะขาผิดจังหวะเดียวบอร์ดพังได้

1มอเตอร์สั่น AH024 → ESP32-C3

ขาบน AH024ขาบน ESP32-C3หมายเหตุ
VCC / +5V ห้ามใช้ 3V3 — มอเตอร์กินไฟกระชากตอนออกตัว จะทำให้บอร์ดรีเซ็ตตัวเอง
GND / −G
IN / SIG / SGPIO4 สัญญาณ PWM — ผ่านการทดสอบบนข้อมือจริงแล้ว

ขาสัญญาณเป็น 3.3V แต่สั่งงานโมดูลได้ปกติ เพราะ AH024 มีทรานซิสเตอร์ขับในตัว

2เซ็นเซอร์ชีพจร GY-MAX30102 → ESP32-C3

ที่อยู่ I2C = 0x57
ขาบนโมดูลขาบน ESP32-C3หมายเหตุ
VIN3V3 ห้ามใช้ 5V — ชิปทำงานที่ 1.8/3.3V
GNDG
SDAGPIO6
SCLGPIO7
INTไม่ต่อโปรแกรมใช้วิธี polling ไม่ต้องใช้ขานี้

3เซ็นเซอร์การเคลื่อนไหว MPU-6050 → ESP32-C3

ที่อยู่ I2C = 0x68
ขาบนโมดูลขาบน ESP32-C3หมายเหตุ
VCC3V3 บอร์ดรับได้ 3–5V แต่ใช้ 3V3 เพื่อให้ระดับลอจิกตรงกับ ESP32
GNDG
SDAGPIO6
SCLGPIO7
AD0ไม่ต่อ ปล่อยลอย = 0x68 · ถ้าต่อเข้า 3V3 จะเปลี่ยนเป็น 0x69
XDA XCL INTไม่ต่อไม่ได้ใช้ในโปรเจกต์นี้

4ต่อรวมทุกอุปกรณ์ → ESP32-C3

ขาบน ESP32-C3ต่อไปที่จำนวนเส้น
5VAH024 VCC1
3V3MAX30102 VIN + MPU-6050 VCC2
GAH024 GND + MAX30102 GND + MPU-6050 GND3
GPIO4AH024 IN1
GPIO6MAX30102 SDA + MPU-6050 SDA2
GPIO7MAX30102 SCL + MPU-6050 SCL2

ต้องใช้รางไฟของ breadboard

ESP32-C3 Super Mini มีขา 3V3 และ G อย่างละ ขาเดียว แต่ต้องจ่าย 3V3 สองเส้นและ GND สามเส้น จึงต้องกระจายผ่านรางไฟ — อย่าพยายามยัดสายหลายเส้นเข้ารูเดียว

ESP32  3V3 ──→ รางบวก (+) ──┬──→ MAX30102  VIN
                            └──→ MPU-6050  VCC

ESP32  G   ──→ รางลบ (−)  ──┬──→ AH024     GND
                            ├──→ MAX30102  GND
                            └──→ MPU-6050  GND

เซ็นเซอร์สองตัวใช้สาย SDA / SCL ร่วมกันได้

I2C ออกแบบมาให้อุปกรณ์หลายตัวต่อขนานบนสายคู่เดียว โดยแยกกันด้วยที่อยู่ — 0x57 กับ 0x68 ไม่ชนกัน ต่อขนานเข้า GPIO6 / GPIO7 ได้เลย ตัวสแกน I2C ในโปรแกรมจะเห็นทั้งสองตัว

แผนที่ขาหลังต่อครบ

ขาสถานะ
GPIO4ใช้แล้ว — มอเตอร์สั่น
GPIO6 / GPIO7ใช้แล้ว — I2C (เซ็นเซอร์ทั้งสองตัว)
GPIO8ห้ามใช้ — ไฟ LED บนบอร์ด และเป็น strapping pin
GPIO9ห้ามใช้ — ปุ่ม BOOT
GPIO0 1 2 3 5 10 20 21ว่าง
ทำไมต้องย้าย I2C มาที่ GPIO6 / GPIO7
ค่าเริ่มต้นของบอร์ดนี้คือ GPIO8 / GPIO9 แต่ทั้งคู่เป็นขาพิเศษ — GPIO8 ต่อกับไฟ LED บนบอร์ด ส่วน GPIO9 คือปุ่ม BOOT ถ้าเซ็นเซอร์ดึง GPIO9 ลงจังหวะที่บอร์ดกำลังบูต บอร์ดจะเข้าโหมดแฟลชแทนที่จะรันโปรแกรม ซึ่งเป็นอาการที่หาสาเหตุยากมาก เพราะดูเหมือนบอร์ดเสีย ทั้งที่จริงแค่ต่อผิดขา
ก่อนเสียบ USB ทุกครั้ง — ตรวจว่าไม่มีลวดทองแดงโผล่มาแตะกัน โดยเฉพาะ 5V กับ G ซึ่งอยู่ติดกันบนบอร์ด เส้นเดียวเกยกัน = ไฟฟ้าลัดวงจรตรงจาก USB
