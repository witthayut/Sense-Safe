LD Haptic Wristband Prototype — live simulator

ESP32-C3 Super Mini + GY-MAX30102 + MPU6050 + AH024 vibration motor, powered from a LiPo battery via a TP4056 charger. Wiring diagram below is a schematic, not a literal breadboard — same electrical connections as the real build.

Wiring diagram

3.3V power GND SDA (GPIO8) SCL (GPIO9) digital drive (GPIO3) = real connection. Lines crossing without a dot are not connected. Breadboard view: modeled on a real full-size breadboard (top+bottom power rails, rows a-e/f-j, columns 1-30). Rail colors follow this project's legend (red=3.3V, black=GND) rather than the photo's red/blue, so GND doesn't clash with the SCL blue used elsewhere. Only +3.3V/GND run through the rails — SDA/SCL/GPIO3 stay direct wires, same as the schematic.
